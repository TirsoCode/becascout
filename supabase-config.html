Falta la configuración de Supabase

La web funciona sin Supabase: la portada y el buscador cargan. Lo que no se guarda es la cuenta con correo y contraseña. Por eso ves esta nota. Para que el registro y la sesión funcionen, hay que poner tres claves en Vercel (ver Variables de entorno):

  • SUPABASE_URL
  • SUPABASE_ANON_KEY
  • SUPABASE_SERVICE_ROLE_KEY

Se añaden en vercel.com → Tu proyecto → Variables de entorno → Añadir.

El botón Crear cuenta de la cabecera sigue ahí. Si las claves están puestas, la cuenta se confirma sola y no hay que registrarse dos veces.

La sesión es una cookie bs_sesion HttpOnly cuyo token vive en la tabla sesiones. Sin las tres variables, el alta de cuenta no se guarda y la API responde «el registro de cuentas no está disponible». Redespliega después de añadir las variables: Vercel no las coge en caliente.

Siempre puedes escribir a privacidad@becascout.com.
